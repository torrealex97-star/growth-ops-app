# Social Media Skills — Carousel Poster de Instagram

Skills panel: `social-media-skills`. Entry points:

- `REFERENCE.md` — plantilla, patrones, paleta, tipografía y copy del carrusel.
- `DESIGN.md` — brief creativo, avatar, recursos tangibles y tabla de traducción.
- `SKILL.md` — este fichero: declaración y flujo.

## Flujo

1. Elegir un tema concreto (guiones, automatizaciones, ofertas, prompts…).
2. Completar el bucle: `VERBO + Nº + RECURSO + para tu próximo X` y la `CLAVE` en MAYÚSCULAS.
3. Escribir `SLIDE 01 (PORTADA)` + 7–9 slides interiores + CTA final + caption.
4. Generar el `PROMPT DE IMAGEN` de la portada.
5. Verificar con la checklist de calidad (max 3 tipografías, 1 acento/slide, nobody copied, 1080x1350).
